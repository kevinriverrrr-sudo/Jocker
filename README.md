# 📊 FunPay Market Assistant

Расширение для браузера, которое помогает в торговле на платформе FunPay.com. Предоставляет инструменты для анализа рынка, сбора статистики и автоматизации рутинных задач.

## 🚀 Возможности

### 📈 Статистика продаж
- **Автоматический сбор данных** о заказах и продажах
- **Визуализация статистики** с графиками за разные периоды
- **Отслеживание дохода** по дням, неделям и месяцам
- **История заказов** с детальной информацией

### 💹 Анализ рынка
- **Анализ цен конкурентов** на аналогичные товары
- **Автоматический расчет** минимальной, максимальной, средней и медианной цены
- **Рекомендации по ценообразованию** для максимальной конкурентоспособности
- **Топ конкурентов** с их ценами
- **История цен** для отслеживания трендов

### 🔔 Уведомления
- **Мгновенные уведомления** о новых заказах
- **Оповещения о новых сообщениях** от покупателей
- **Звуковые уведомления** (опционально)
- **Настраиваемые параметры** уведомлений

### 🎨 Удобный интерфейс
- **Боковая панель** на страницах FunPay с быстрым доступом к функциям
- **Popup окно** с детальной статистикой и настройками
- **Темная тема** для комфортной работы
- **Адаптивный дизайн** для разных размеров экрана

## 📦 Установка

### Для Chrome / Edge / Brave

1. Скачайте или клонируйте этот репозиторий:
```bash
git clone https://github.com/yourusername/funpay-assistant.git
```

2. Откройте браузер и перейдите на страницу расширений:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`

3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу

4. Нажмите **Загрузить распакованное расширение** (Load unpacked)

5. Выберите папку с расширением (где находится файл `manifest.json`)

6. Расширение установлено! Вы увидите иконку в панели инструментов браузера

### Для Firefox

1. Откройте Firefox и перейдите на `about:debugging#/runtime/this-firefox`

2. Нажмите **Загрузить временное дополнение** (Load Temporary Add-on)

3. Выберите файл `manifest.json` из папки с расширением

4. Расширение будет работать до перезапуска браузера

## 🎯 Использование

### Первое использование

1. После установки откройте сайт [FunPay.com](https://funpay.com)
2. Войдите в свой аккаунт продавца
3. Вы увидите панель расширения в правой части экрана
4. Кликните на иконку расширения для открытия детальной статистики

### Основные функции

#### 📊 Просмотр статистики
1. Откройте popup расширения (клик на иконку)
2. Перейдите на вкладку **Статистика**
3. Выберите период для анализа (сегодня, неделя, месяц, всё время)
4. Просматривайте графики и данные о продажах

#### 💰 Анализ цен конкурентов
1. Откройте страницу с товаром или категорией на FunPay
2. Кликните на иконку расширения
3. Перейдите на вкладку **Рынок**
4. Нажмите **Провести анализ цен**
5. Получите детальную информацию о ценах и рекомендации

Либо используйте кнопку на боковой панели:
1. Откройте нужную страницу на FunPay
2. Найдите панель расширения справа
3. Нажмите **Проанализировать цены конкурентов**
4. Результаты появятся в панели

#### ⚙️ Настройки
1. Откройте popup расширения
2. Перейдите на вкладку **Настройки**
3. Настройте параметры:
   - **Уведомления**: включите/выключите различные типы уведомлений
   - **Статистика**: настройте автоматический сбор данных
   - **Интерфейс**: темная тема, показ панели
   - **Обновления**: частота обновления данных
4. Нажмите **Сохранить настройки**

### Боковая панель

На страницах FunPay отображается боковая панель с быстрым доступом к функциям:

- **🔔 Уведомления**: статус мониторинга новых заказов
- **📈 Быстрая статистика**: заказы и доход за сегодня, активные лоты
- **💰 Анализ рынка**: кнопка для быстрого анализа цен

Вы можете свернуть/развернуть панель кнопкой в заголовке.

## 🛠️ Технические детали

### Структура проекта

```
funpay-assistant/
├── manifest.json           # Манифест расширения
├── background.js          # Background service worker
├── content.js            # Content script для интеграции с FunPay
├── popup.html           # HTML popup интерфейса
├── popup.js            # JavaScript popup интерфейса
├── popup-styles.css   # Стили popup
├── styles.css        # Стили для content script
├── icons/           # Иконки расширения
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md       # Документация
```

### Архитектура

**Content Script** (`content.js`):
- Внедряется на все страницы FunPay.com
- Собирает данные о заказах, ценах, лотах
- Отслеживает изменения на странице (новые заказы, сообщения)
- Внедряет UI панель на страницу
- Взаимодействует с background service

**Background Service** (`background.js`):
- Обрабатывает фоновые задачи
- Управляет уведомлениями
- Хранит и обрабатывает данные
- Координирует работу между вкладками

**Popup Interface** (`popup.html`, `popup.js`):
- Предоставляет детальный интерфейс для просмотра статистики
- Управление настройками
- Визуализация данных (графики, таблицы)

### Хранение данных

Расширение использует `chrome.storage.local` для хранения:
- **stats**: статистика по дням (заказы, доход)
- **orders**: история заказов
- **marketAnalysis**: результаты анализов рынка
- **priceHistory**: история цен
- **settings**: пользовательские настройки

## ⚙️ Настройки

### Доступные параметры

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `notifyOrders` | Уведомления о новых заказах | ✅ Включено |
| `notifyMessages` | Уведомления о новых сообщениях | ✅ Включено |
| `soundNotifications` | Звуковые уведомления | ❌ Выключено |
| `autoCollect` | Автоматический сбор статистики | ✅ Включено |
| `trackPrices` | Отслеживание цен конкурентов | ✅ Включено |
| `showPanel` | Показывать панель на FunPay | ✅ Включено |
| `darkMode` | Темная тема | ❌ Выключено |
| `updateInterval` | Интервал обновления (сек) | 30 |

## 🔒 Конфиденциальность

- **Расширение работает полностью локально** на вашем компьютере
- **Не отправляет данные** на внешние серверы
- **Не собирает личную информацию**
- Требует доступ только к сайту FunPay.com
- Все данные хранятся в локальном хранилище браузера

## 📊 Примеры использования

### Пример 1: Оптимизация цены товара
1. Откройте категорию вашего товара на FunPay
2. Запустите анализ рынка через боковую панель
3. Изучите статистику:
   - Минимальная цена: 450₽
   - Медианная цена: 520₽
   - Максимальная цена: 650₽
4. Установите цену 510₽ (чуть ниже медианы)
5. Получите конкурентное преимущество!

### Пример 2: Отслеживание продаж
1. Расширение автоматически фиксирует все заказы
2. В конце дня откройте статистику
3. Посмотрите график продаж за неделю
4. Определите лучшие дни для продаж
5. Оптимизируйте расписание работы

### Пример 3: Быстрая реакция на заказы
1. Включите уведомления о новых заказах
2. Получайте мгновенные оповещения
3. Быстро отвечайте покупателям
4. Повышайте рейтинг и продажи

## 🐛 Известные проблемы

- Расширение может не работать корректно если FunPay изменит структуру сайта
- В Firefox расширение удаляется при перезапуске (временное дополнение)
- Некоторые статистические данные могут быть неточными из-за особенностей парсинга
