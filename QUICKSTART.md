# ⚡ Быстрый старт

## Шаг 1: Создайте иконки

**ВАЖНО:** Перед установкой расширения нужно создать PNG иконки!

### Самый простой способ - онлайн конвертер:

1. Откройте https://www.aconvert.com/image/svg-to-png/
2. Загрузите файл `icons/icon.svg` из этого проекта
3. В настройках укажите размер **16x16** и конвертируйте
4. Скачайте и переименуйте в `icon16.png`, сохраните в папку `icons/`
5. Повторите для размеров **48x48** (→ `icon48.png`) и **128x128** (→ `icon128.png`)

### Или используйте любой из этих онлайн инструментов:
- https://cloudconvert.com/svg-to-png
- https://www.zamzar.com/convert/svg-to-png/
- https://convertio.co/svg-png/

### Или используйте готовые иконки (быстрый способ для теста):

Создайте 3 простых файла PNG любым графическим редактором:
- `icon16.png` - 16x16 пикселей, любой цвет (например, синий квадрат)
- `icon48.png` - 48x48 пикселей, любой цвет  
- `icon128.png` - 128x128 пикселей, любой цвет

Сохраните их в папку `icons/`

## Шаг 2: Установите расширение

### Для Chrome / Brave / Edge:

1. Откройте браузер
2. Введите в адресной строке:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
3. Включите **"Режим разработчика"** (переключатель справа вверху)
4. Нажмите **"Загрузить распакованное расширение"**
5. Выберите папку этого проекта (где находится `manifest.json`)
6. Готово! ✅

## Шаг 3: Используйте расширение

1. Откройте https://funpay.com и войдите в аккаунт
2. Справа появится панель **📊 FunPay Assistant**
3. Кликните на иконку расширения в панели инструментов браузера для открытия детальной статистики
4. Настройте уведомления и другие опции во вкладке **⚙️ Настройки**

## Основные функции

### 📊 Статистика
- Автоматический сбор данных о заказах
- Графики продаж за разные периоды
- Отслеживание дохода

### 💰 Анализ рынка
1. Откройте страницу товара на FunPay
2. Нажмите **"Проанализировать цены конкурентов"** на боковой панели
3. Получите рекомендации по оптимальной цене

### 🔔 Уведомления
- Получайте мгновенные уведомления о новых заказах
- Настраивайте типы уведомлений в настройках

## Проблемы?

**Панель не появляется:**
- Убедитесь, что вы на сайте funpay.com
- Перезагрузите страницу (F5)
- Проверьте, что расширение включено

**Иконки не работают:**
- Создайте файлы icon16.png, icon48.png, icon128.png в папке icons/
- См. Шаг 1 выше
