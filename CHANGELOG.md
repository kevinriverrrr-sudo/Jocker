# Changelog

Все важные изменения в проекте FunPay Market Assistant будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект следует [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2025-11-04

### Добавлено
- 📊 **Сбор и анализ статистики продаж**
  - Автоматический сбор данных о заказах
  - Подсчет дохода по дням, неделям, месяцам
  - Визуализация графиков продаж
  - История последних заказов

- 💹 **Анализ рынка и цен конкурентов**
  - Автоматический парсинг цен на странице
  - Расчет минимальной, максимальной, средней и медианной цены
  - Топ-5 конкурентов с ценами
  - Рекомендации по ценообразованию
  - История анализов рынка

- 🔔 **Система уведомлений**
  - Push-уведомления о новых заказах
  - Уведомления о новых сообщениях
  - Опция звуковых уведомлений
  - Настраиваемые типы уведомлений

- 🎨 **Пользовательский интерфейс**
  - Боковая панель на страницах FunPay с быстрой статистикой
  - Popup интерфейс с тремя вкладками (Статистика, Рынок, Настройки)
  - Темная тема для комфортной работы
  - Адаптивный дизайн
  - Возможность скрывать/показывать элементы

- ⚙️ **Настройки и конфигурация**
  - Управление уведомлениями
  - Настройка автосбора статистики
  - Отслеживание цен конкурентов
  - Настройка интервала обновления данных
  - Функция очистки данных
  - Сброс настроек к значениям по умолчанию

- 📈 **Визуализация данных**
  - График продаж за последние 7 дней
  - Карточки с ключевыми метриками
  - Цветовая индикация важных показателей

- 🛠️ **Техническая реализация**
  - Manifest V3 для совместимости с современными браузерами
  - Background Service Worker для фоновой работы
  - Content Script для интеграции с FunPay.com
  - Локальное хранилище данных (chrome.storage.local)
  - Мониторинг изменений на странице (MutationObserver)

### Инструменты
- 🛠️ Скрипт для создания иконок (create_icons.sh)
- 🐍 Python скрипт для генерации иконок (create_simple_icons.py)
- 🎨 SVG иконка для конвертации
- 📝 .gitignore для управления версиями

### Известные ограничения
- Расширение работает только на открытых вкладках FunPay
- Статистика не синхронизируется между устройствами
- Требуется ручное создание PNG иконок перед установкой
- В Firefox расширение устанавливается как временное
