## Описание ключевых файлов

### Основные компоненты

#### manifest.json
- **Назначение:** Конфигурация расширения
- **Версия манифеста:** 3 (Manifest V3)
- **Разрешения:** storage, notifications, alarms
- **Домены:** funpay.com и поддомены

#### background.js (1104 строки)
**Основной класс:** `BackgroundService`

**Ключевые методы:**
- `init()` - Инициализация сервиса
- `handleNewOrder()` - Обработка новых заказов
- `handleMarketAnalysis()` - Обработка анализа рынка
- `sendNotification()` - Отправка уведомлений
- `saveData()` - Сохранение данных
- `setupAlarms()` - Настройка периодических задач

**Хранилище данных:**
- `stats` - Статистика по дням
- `orders` - История заказов
- `marketAnalysis` - Результаты анализов
- `priceHistory` - История цен
- `settings` - Настройки пользователя

#### content.js (711 строк)
**Основной класс:** `FunPayAssistant`

**Ключевые методы:**
- `init()` - Инициализация на странице
- `injectUI()` - Внедрение панели
- `setupOrderMonitoring()` - Мониторинг заказов
- `setupPriceMonitoring()` - Мониторинг цен
- `collectStatistics()` - Сбор статистики
- `analyzeCompetitors()` - Анализ конкурентов
- `calculateMedian()` - Вычисление медианы

**DOM взаимодействие:**
- MutationObserver для отслеживания изменений
- Парсинг элементов страницы FunPay
- Внедрение UI компонентов

#### popup.js (623 строки)
**Основной класс:** `PopupManager`

**Функции:**
- Управление вкладками
- Отображение статистики
- Рисование графиков (Canvas API)
- Настройка параметров
- Взаимодействие с background и content scripts

**Вкладки:**
1. **Статистика** - графики, карточки, история заказов
2. **Рынок** - анализ, конкуренты, рекомендации
3. **Настройки** - конфигурация всех параметров

### Стили

#### popup-styles.css (650 строк)
- Адаптивный grid layout

## Поток данных

### 1. Сбор статистики
```
FunPay Page → content.js (parsing) → background.js (processing) 
→ chrome.storage → popup.js (visualization)
```

### 2. Анализ рынка
```
User Action → content.js (collect prices) → calculate stats 
→ background.js (save) → content.js (display results)
```

### 3. Уведомления
```
New Order Detected → content.js (MutationObserver) 
→ background.js (notification) → Browser Notification API
```

## Используемые технологии

### Core
- **JavaScript (ES6+)** - Основной язык
- **HTML5** - Разметка popup
- **CSS3** - Стилизация и анимации

### Browser APIs
- **Chrome Extension API** (Manifest V3)
- **chrome.storage.local** - Локальное хранилище
- **chrome.notifications** - Push уведомления
- **chrome.alarms** - Периодические задачи
- **chrome.runtime** - Межскриптовое общение
- **chrome.tabs** - Управление вкладками

### DOM APIs
- **MutationObserver** - Отслеживание изменений DOM
- **Canvas API** - Рисование графиков
- **localStorage/sessionStorage** - Дополнительное хранение

### Дизайн
- **CSS Grid** - Раскладка элементов
- **Flexbox** - Гибкие контейнеры
- **CSS Variables** - Темизация
- **Transitions/Animations** - Плавность

## Безопасность

### Разрешения
- ✅ `storage` - для локального хранения данных
- ✅ `notifications` - для push-уведомлений
- ✅ `alarms` - для периодических обновлений
- ✅ `https://funpay.com/*` - доступ только к FunPay

### Приватность
- ❌ Нет доступа к другим сайтам
- ❌ Нет отправки данных на внешние серверы
- ❌ Нет сбора личной информации
- ✅ Все данные хранятся локально
- ✅ Open source код
