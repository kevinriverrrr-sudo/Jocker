# 🚀 Инструкция по установке FunPay Market Assistant

## Предварительные требования

Перед установкой расширения необходимо создать иконки.

### Создание иконок

Иконки необходимы для корректной работы расширения. Выполните один из следующих вариантов:

#### Вариант 1: Автоматическое создание (Linux/Mac)

```bash
cd icons
./create_icons.sh
```

Скрипт автоматически создаст PNG иконки из SVG файла.

#### Вариант 2: Ручное создание с ImageMagick

```bash
cd icons

# Создайте иконки командами:
convert -background none icon.svg -resize 16x16 icon16.png
convert -background none icon.svg -resize 48x48 icon48.png
convert -background none icon.svg -resize 128x128 icon128.png
```

#### Вариант 3: Онлайн конвертер

1. Откройте https://cloudconvert.com/svg-to-png
2. Загрузите файл `icons/icon.svg`
3. Создайте 3 версии с размерами: 16x16, 48x48, 128x128 пикселей
4. Сохраните их как `icon16.png`, `icon48.png`, `icon128.png` в папку `icons/`

#### Вариант 4: Используйте простые цветные квадраты (для тестирования)

Если вам нужно быстро протестировать расширение, создайте простые иконки с помощью Python:

```bash
cd icons
python3 << 'EOF'
from PIL import Image

# Создаём простые иконки с градиентом
def create_icon(size, filename):
    img = Image.new('RGB', (size, size), color=(102, 126, 234))
    img.save(filename)

create_icon(16, 'icon16.png')
create_icon(48, 'icon48.png')
create_icon(128, 'icon128.png')
print("Иконки созданы!")
EOF
```

## Установка в Chrome / Brave / Edge

1. **Убедитесь, что иконки созданы** (см. выше)

2. **Откройте страницу расширений:**
   - Chrome: введите `chrome://extensions/` в адресной строке
   - Edge: введите `edge://extensions/`
   - Brave: введите `brave://extensions/`

3. **Включите режим разработчика:**
   - Найдите переключатель "Режим разработчика" (Developer mode) в правом верхнем углу
   - Переключите его в положение ON

4. **Загрузите расширение:**
   - Нажмите кнопку "Загрузить распакованное расширение" (Load unpacked)
   - Выберите папку `/workspace` (где находится файл `manifest.json`)
   - Нажмите "Выбрать папку" (Select folder)

5. **Готово!**
   - Расширение появится в списке установленных
   - Иконка расширения появится на панели инструментов браузера

## Установка в Firefox

1. **Убедитесь, что иконки созданы**

2. **Откройте страницу отладки:**
   - Введите в адресной строке: `about:debugging#/runtime/this-firefox`

3. **Загрузите временное дополнение:**
   - Нажмите "Загрузить временное дополнение" (Load Temporary Add-on)
   - Перейдите в папку `/workspace`
   - Выберите файл `manifest.json`
   - Нажмите "Открыть"

4. **Важно:**
   - Расширение будет активно только до перезапуска Firefox
   - Для постоянной установки нужно подписать расширение через AMO

## Проверка установки

После установки:

1. **Откройте FunPay.com**
   - Перейдите на https://funpay.com
   - Войдите в свой аккаунт

2. **Проверьте боковую панель:**
   - Справа на странице должна появиться панель "📊 FunPay Assistant"
   - Панель можно свернуть/развернуть кнопкой в заголовке

3. **Откройте popup:**
   - Кликните на иконку расширения в панели инструментов
   - Откроется окно с вкладками: Статистика, Рынок, Настройки

4. **Проверьте уведомления:**
   - Откройте настройки расширения
   - Убедитесь, что уведомления включены
   - При появлении новых заказов будут приходить уведомления

## Возможные проблемы

### Расширение не загружается

**Проблема:** Ошибка "Manifest file is missing or unreadable"

**Решение:**
- Убедитесь, что вы выбрали правильную папку (где находится `manifest.json`)
- Проверьте, что файл `manifest.json` не поврежден

### Иконки не отображаются

**Проблема:** В консоли ошибки "Failed to load icon"

**Решение:**
- Создайте файлы `icon16.png`, `icon48.png`, `icon128.png` в папке `icons/`
- См. раздел "Создание иконок" выше

### Панель не появляется на FunPay

**Проблема:** На странице FunPay.com не видно боковой панели

**Решение:**
- Проверьте, что вы на сайте funpay.com (не на другом домене)
- Откройте консоль разработчика (F12) и проверьте наличие ошибок
- Убедитесь, что в настройках расширения включена опция "Показывать панель"
- Перезагрузите страницу (F5)

### Расширение не собирает статистику

**Проблема:** В статистике нет данных

**Решение:**
- Убедитесь, что в настройках включена опция "Автоматически собирать статистику"
- Расширение начнет собирать данные с момента установки
- Для появления статистики нужно совершить несколько действий на FunPay

### Firefox: расширение пропадает после перезапуска

**Проблема:** После перезапуска Firefox расширение исчезает

**Решение:**
- Это нормальное поведение для временных дополнений
- Для постоянной установки нужно:
  1. Упаковать расширение в .xpi файл
  2. Подписать его через Mozilla AMO
  3. Или установить Firefox Developer Edition для постоянной загрузки

## Обновление расширения

Если вы внесли изменения в код:

1. **Chrome/Edge/Brave:**
   - Откройте `chrome://extensions/` (или аналог)
   - Найдите FunPay Market Assistant
   - Нажмите кнопку "Обновить" (круговая стрелка)
   - Или нажмите Ctrl+R на странице расширений

2. **Firefox:**
   - Откройте `about:debugging#/runtime/this-firefox`
   - Нажмите "Перезагрузить" (Reload) напротив расширения

## Удаление расширения

1. **Chrome/Edge/Brave:**
   - Откройте страницу расширений
   - Найдите FunPay Market Assistant
   - Нажмите "Удалить" (Remove)

2. **Firefox:**
   - Откройте `about:debugging#/runtime/this-firefox`
   - Нажмите "Удалить" напротив расширения

## Дополнительная помощь

Если у вас возникли проблемы:

1. Проверьте консоль разработчика (F12) на наличие ошибок
2. Убедитесь, что все файлы расширения на месте
3. Проверьте, что иконки созданы
4. Попробуйте переустановить расширение
5. Создайте Issue в репозитории с описанием проблемы
